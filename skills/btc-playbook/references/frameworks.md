# Frameworks: when they earn their place

Frameworks compress a structured judgement. Use them to structure thinking, not to fill slides.

| Framework | Earns its place when | Decoration when |
|---|---|---|
| First principles | Brief is unfamiliar or the usual framing seems wrong | Label for ordinary analysis |
| Issue tree / MECE | Showing the solution space was covered | Branches overlap |
| Five Whys | Stated problem is a symptom | Drawn as a diagram, no insight reached |
| Jobs To Be Done | Persona work; avoiding solution-first | Fill-in-the-blank sentence, no evidence |
| RICE | 5+ candidates needing a defensible ranking | Inputs invented → false precision |
| ICE | Short on time | Same, more so |
| Impact/Effort 2×2 | Quick visual ranking | Items placed by gut, axes unlabelled |
| MoSCoW | Defining MVP scope, esp. the Won't list | Everything is a Must |
| Kano | Arguing a feature delights disproportionately | No user input behind it |
| Weighted scoring | The criteria ARE the argument | Weights picked to get the answer |
| Personas | Justifying one group over another | Demographic sketches |
| Empathy map | Emotion drives behaviour | Speculation as insight |
| Journey map | Locating where the problem lives | No metric row; connects to nothing |
| Service blueprint | Ops-heavy, real backstage complexity | Simple consumer flow |
| North Star + inputs | Almost always (default) | NSM is a vanity metric |
| AARRR | Consumer growth with a clear funnel | B2B with a different funnel |
| HEART | UX quality is the subject | Five metrics, no priority |
| Guardrails & counter-metrics | Any optimisation with a plausible victim | Omitted (the usual case) |
| OKRs | Steering a team over a quarter | Synonym for "goals" |
| TAM/SAM/SOM | Entry & monetisation cases | Numbers copied from a search result |
| Porter's Five Forces | Entering an industry with strong incumbents/suppliers | Applied to a feature decision |
| SWOT | Rarely | Almost always; prefer a right-to-win argument |
| Ansoff | Naming the kind of growth bet | Shown, informs nothing |
| Business / Lean canvas | Whole model in question | Summary slide repeating content |
| Blue Ocean / ERRC | Competing on a different axis | "Create" holds what rivals already do |
| Value chain | Where structural advantage sits | Drawn generically |
| STP | "Who first and why" in GTM | Segments named, never used |
| Bullseye | Channel choice genuinely open | All channels equally promising |
| RACI | Ops/governance sections | No org dimension in the case |
| Phase gates | Any roadmap | Gates without thresholds |
