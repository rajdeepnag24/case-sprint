# Submission checklist (cheapest marks to lose)

- [ ] Submit early; never in the last 15 minutes.
- [ ] File naming, format and destination exactly as the guidelines say. **Name on the file** if
      allowed (a peer was once cut for an unnamed file).
- [ ] Hard limits obeyed mechanically: slides / pages / words / minimum font size.
- [ ] Every required section present, in the order asked if one was given.
- [ ] Links set to public; opened in an incognito window, logged out, on phone and laptop.
- [ ] Prototype link is a real hyperlink on an early slide AND in the form.
- [ ] Backup: recorded walkthrough or screenshot appendix in case hosting breaks.
- [ ] Every number traces to a stated assumption (appendix or footnote).
- [ ] Same number identical everywhere it appears.
- [ ] Executive summary up front if asked (or if the deck is long).
- [ ] Ambiguity in the guidelines → asked the placement rep, did not assume the favourable reading.
- [ ] Kept the artefacts (deck, prototype, research, reasoning notes) for the interview.
