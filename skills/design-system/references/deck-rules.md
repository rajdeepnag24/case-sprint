# Deck rules

- **Canvas**: 16:9. Margins 48 px (≈0.5 in) all sides. Ground `ground`, exhibits on `surface` cards.
- **Headline**: the claim, `typeScale.slide.headline`, ink, sentence case, max 2 lines.
- **Subhead** (optional): one line of context, `inkMuted`.
- **One exhibit per slide** that the eye lands on. Exhibit labels at `exhibitLabel`.
- **Body**: max 3–5 evidence lines, numbers first, in `body` size. Never below the brief's font floor.
- **Colour**: neutral greys carry structure; `brand.primary` for the main series and key shapes;
  `brand.accent` once per slide at most, for the single thing to notice (callout, highlighted bar).
- **Numbers**: tabular figures (`font.numeric`) in tables; units in headers (₹ cr, %, users M).
- **Charts**: chart palette in order; label lines directly instead of legends where possible; no
  3D, no gradients; one message per chart, stated in the headline.
- **Footer**: source line at `footer` size, bottom-left; slide number bottom-right.
- **Exec summary**: the headline sequence as 4–6 numbered lines, accent on the recommendation.
- **Appendix**: same grid, `inkMuted` "Appendix" tag top-right.
- **Don't**: icons as decoration, stock photos, more than one accent, centred body text, text
  boxes wider than the exhibit.

## Exhibit picker
| Block | Default exhibit |
|---|---|
| Problem | Mechanism diagram or 2–3 stat callouts |
| Right-to-win | Table: asset · why entrants lack it · how the plan uses it |
| Personas | 2–3 cards: context, job, pain, workaround, why prioritised |
| Journey | Stage columns × rows (action, touchpoint, emotion, pain, metric) |
| MVP | Two columns: vision vs formulation + "Won't" list + hypothesis box |
| Prioritisation | Scored table or labelled impact/effort 2×2 |
| Metrics | Tree: North Star → inputs; side panel guardrails/counter-metrics with targets |
| Economics | Waterfall or small table; assumptions in appendix |
| GTM | Sequenced timeline: segment/city → channel → economics |
| Options | Matrix: options × criteria, chosen highlighted, rejection reasons row |
| Roadmap | Phases with gate thresholds |
| Risks | Table: risk · mitigation · leading indicator |
