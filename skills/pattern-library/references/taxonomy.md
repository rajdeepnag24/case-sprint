# Pattern taxonomy

| Pattern type | Examples to look for |
|---|---|
| onboarding | progressive sign-up, value-first before login, permission priming |
| activation | first-success moment, setup checklists, templates, sample data |
| discovery | search with filters, personalised feeds, curated collections, "because you…" |
| decision-support | comparisons, reviews, badges, price history, delivery-time promises |
| trust-and-safety | verification badges, escrow, ratings with context, refunds, masked contact |
| checkout-and-payment | one-tap pay, saved methods, BNPL, split pay, UPI intents, order summary |
| retention-and-habit | streaks, reminders, saved lists, subscriptions, recaps (e.g., Wrapped) |
| social-and-referral | invite rewards, group orders, sharing cards, social proof |
| monetisation | freemium walls, tiers, add-ons, ads placement, paid boosts |
| notifications | transactional vs marketing, digest, quiet hours, deep links |
| empty-and-error-states | helpful empties, retry, offline mode, partial results |
| ai-assist | copilots, summaries, smart compose, agents with approval steps, explanations |
| b2b-admin | role permissions, audit logs, bulk actions, dashboards, alerts |
| marketplace-supply | seller onboarding, pricing tools, payouts, performance dashboards |
| accessibility-and-inclusion | vernacular, voice, large-text modes, low-bandwidth modes |
